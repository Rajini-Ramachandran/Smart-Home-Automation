# 🏠 Smart Home Automation System

## Problem Statement
People with physical disabilities often struggle to control everyday home devices 
independently — adjusting lights, managing appliances, or responding to changing 
environmental conditions requires physical effort that may not always be possible. 
At the same time, unattended devices and manual control systems contribute 
significantly to unnecessary energy consumption in households. There is a clear 
need for an accessible, automated solution that empowers disabled individuals to 
manage their home environment effortlessly while actively conserving energy.

## Solution
We built a Smart Home Automation System that uses real-time sensor data to 
automatically control home devices — reducing energy waste without requiring any 
manual effort from the user. Through a mobile interface, users with disabilities 
can monitor and control their home environment remotely with minimal physical 
interaction, making independent living more accessible and energy consumption 
more efficient.

## How It Works
1. **Sensor Layer** — Light sensors continuously monitor real-time environmental 
   conditions inside the home.
2. **Backend API** — A Python-based API processes incoming sensor readings and 
   triggers device actions automatically when conditions cross defined thresholds.
3. **Automation Logic** — Devices turn on or off based on live sensor data 
   (e.g., lights activate when a room gets dark, turn off when natural light 
   is sufficient) — requiring zero manual input.
4. **Mobile Interface** — Users can view live sensor data and manually control 
   devices through an accessible Ionic mobile app, designed for ease of use 
   for individuals with limited mobility.

## Features
- ♿ Designed with accessibility in mind for users with physical disabilities
- 📡 Real-time light sensor monitoring for automated device control
- ⚡ Energy conservation through smart automation and threshold-based triggers
